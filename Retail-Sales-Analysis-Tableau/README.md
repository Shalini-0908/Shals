# Retail Sales Analysis Dashboard (Tableau)

## 🎯 Objective
To analyze retail sales performance and identify trends in profit, sales, discount impact, and customer segments using Tableau.

## 📊 Dashboard Preview
![Tableau Dashboard](Screenshot%202026-05-06%20171238.png)


## 📂 Dataset
- Source: Superstore Dataset (Tableau Public / Kaggle)
- Contains: Sales, Profit, Discount, Quantity, Region, Category, Sub-Category, Customer Segment

## 🛠 Tools Used
- Tableau
- Excel (Data preparation)

## 🔍 Key Insights
- West region shows highest sales performance
- Technology category generates highest profit
- Office Supplies has low profit margin despite high sales
- Consumer segment contributes the most revenue
- High discount values reduce overall profitability
- Some sub-categories generate negative profit

## 📈 Dashboard Features
- Sales vs Profit analysis
- Regional performance breakdown
- Category and Sub-category analysis
- Customer segment insights
- Interactive filters (Region, Category, Date)

## 📌 Description
Built an interactive Tableau dashboard using the Superstore dataset to analyze sales, profit, discounts, and customer segments. Created visualizations and filters to identify business trends and support data-driven decision-making.

## 🧠 Skills
Tableau, Data Visualization, Dashboard Development, Data Analysis, Business Intelligence

## 📌 Conclusion
This dashboard helps businesses understand sales performance, improve profitability, and make data-driven decisions for better growth.
