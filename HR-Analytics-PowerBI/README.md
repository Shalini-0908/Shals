# HR Analytics Dashboard

## 🎯 Objective
To analyze employee data and identify key factors affecting attrition, job satisfaction, and salary trends.

## 📊 Dashboard Preview
![HR Analytics Dashboard](Screenshot%202026-05-07%20155957.png)

## 📂 Dataset
Source: Kaggle HR dataset  
Contains employee demographics, salary, department, attrition status

## 🛠 Tools & Technologies
Power BI, Power Query, DAX, Data Modeling

## 🔍 Key Insights
- Sales department has highest attrition
- Low salary group shows higher exit rate
- Overtime increases attrition risk
- Job satisfaction strongly affects retention
  
## 📌 Description
Developed an interactive HR Analytics Dashboard using Power BI to analyze employee demographics, job satisfaction, salary trends, and workforce distribution. Created dynamic visualizations and KPI metrics to support data-driven HR decision-making.

## 🧠 Skills
Power BI, Power Query, DAX, Data Visualization, Data Modeling, Dashboard Development, KPI Analysis
