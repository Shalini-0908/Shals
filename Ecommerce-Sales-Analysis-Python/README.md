# 📊 E-Commerce Customer & Sales Analysis Using Python

## 🚀 Project Overview

This project focuses on analyzing e-commerce customer behavior, sales performance, revenue trends, and product performance using Python. The analysis was performed on multiple business datasets to uncover valuable insights that can support data-driven decision-making.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## 📂 Datasets Used

* customers.csv
* orders.csv
* monthly_revenue.csv
* product_summary.csv

## 📈 Key Analyses Performed

### 💰 Revenue Analysis

* Monthly Revenue Trend
* Orders Trend Analysis
* Average Order Value Analysis

### 🛒 Product Analysis

* Top Products by Revenue
* Revenue by Category
* Product Rating Analysis
* Return Rate Analysis

### 👥 Customer Analysis

* Customer Churn Analysis
* Membership Tier Analysis
* Age Distribution
* Customer Acquisition Channel Analysis

## 🔍 Key Insights

* Identified top-performing products and categories driving revenue.
* Analyzed customer churn and retention patterns.
* Evaluated customer spending behavior across membership tiers.
* Examined monthly sales performance and business growth trends.
* Investigated customer acquisition channels and purchasing behavior.
