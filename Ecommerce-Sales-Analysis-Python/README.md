# E-Commerce Customer & Sales Analysis Using Python

## Project Overview

Analyzed customer, sales, revenue, and product datasets using Python to identify key business trends and performance metrics. Performed exploratory data analysis (EDA) and developed visualizations to evaluate customer behavior, revenue growth, product performance, and customer retention.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## Key Analyses

* Monthly Revenue Trend
* Orders Trend Analysis
* Customer Churn Analysis
* Membership Tier Analysis
* Product Performance Analysis
* Revenue by Category
* Customer Acquisition Analysis

## Skills Demonstrated

Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization, Sales Analytics, Customer Analytics, Business Intelligence
