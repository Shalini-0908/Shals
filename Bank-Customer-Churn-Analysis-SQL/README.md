# 🏦 Bank Customer Churn Analysis Using SQL

## 📌 Project Overview

This project analyzes customer churn in a banking dataset using SQL. The objective was to identify factors influencing customer attrition and generate business insights to support customer retention strategies.

## 🛠️ Tools & Technologies

- SQL
- MySQL Workbench

## 📊 Key Analyses

- Customer Distribution by Country
- Churn Analysis by Country
- Churn Analysis by Gender
- Churn Analysis by Age Group
- Active vs Inactive Customer Analysis
- Product Usage Analysis
- Credit Score Analysis
- Balance Category Analysis

## 🔍 Key Insights

- Germany had the highest customer churn rate.
- Female customers showed higher churn rates than male customers.
- Customers above 50 years old had the highest churn rate.
- Inactive customers were significantly more likely to churn.
- Customers with 3–4 products showed extremely high churn rates.
- High-balance customers had the highest churn rate among balance categories.
