# Sales Analytics Dashboard (Excel + Power Query)

## 🎯 Objective
To analyze sales performance using Excel and Power Query by cleaning, transforming, and visualizing Superstore dataset data to identify business trends and performance insights.

## 📊 Dashboard Preview
![Excel Dashboard](Screenshot%202026-04-29%20180709.png)

## 📂 Dataset
- Source: Superstore Dataset (Kaggle / sample dataset)
- Contains: Sales, Profit, Quantity, Discount, Category, Sub-Category, Region, Customer Segment

## 🛠 Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts

## 🔄 Process Followed
- Data cleaning using Power Query
- Removed duplicates and handled missing values
- Data transformation and formatting
- Built pivot tables for analysis
- Created interactive dashboard with charts

## 🔍 Key Insights
- Technology category generates highest profit
- High discount values reduce profit margins
- West region performs best in overall sales
- Certain sub-categories show low or negative profit
- Consumer segment contributes most to revenue

## 📈 Dashboard Features
- Sales and Profit analysis
- Category-wise performance breakdown
- Regional analysis
- Interactive Pivot Charts and Filters

## 📌 Description
Developed an interactive sales dashboard using Excel and Power Query with the Superstore dataset. Performed data cleaning, transformation, and reporting to analyze sales, profit, quantity, and discount metrics.

## 🧠 Skills
Excel, Power Query, Data Cleaning, Data Transformation, Pivot Tables, Pivot Charts, Reporting, Data Analysis
